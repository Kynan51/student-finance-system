Install Student Finance on your phone or computer

This is a website that can also be installed like an app (a Progressive Web App). It opens in its own window and from your home screen, but it still needs the internet to load and save your records.

If no install button appears, use your browser's menu as described below.

Android (Chrome)

  1. Open the site in Chrome.
  2. Tap the ⋮ menu.
  3. Tap Install app or Add to Home screen.

iPhone (Safari)

  1. Open the site in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.

Windows / Mac (Chrome or Edge)

  1. Look for the install icon at the right of the address bar.
  2. Or open the browser menu and choose Install Student Finance.

What works offline?

Only the app shell and an offline notice. Your financial data is never cached on the device, so saving and viewing records needs a connection.

Installation requires HTTPS on a real domain. On your own computer, http://localhost:8000 also works.
